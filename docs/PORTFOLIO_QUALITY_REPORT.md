## 홈페이지 구조 개선

- **목록**: 탭마다 첫 카드가 2칸 대표 카드(가로형 — 화면 + 이름·요약·업무 흐름 단계). 전체 탭 대표 = `featured`(FITY). 마지막 줄이 비면 마지막 카드가 넓어짐. 첫 화면 11장 + 더 보기 12장씩 → 3열·2열 모두 빈칸 없음. 카드 위 분류 줄은 산업명.
- **화면 대기 카드 14개**: 빈 브라우저 틀 대신 업무 흐름(번호 목록 · 단계 문장 · 단계 수+처음→끝, 상세 layout에 따라) + 프로젝트 강조색 배경 + "UI 준비 중" 표시. 가짜 UI 없음.
- **상세**: 대기 프로젝트 표지 = 업무 흐름 패널(단계 제목·설명·플랫폼). 이미지 프로젝트는 핵심 화면을 크게, 보조 화면은 화면+설명 카드(2열, 홀수면 첫 카드 한 줄)로. 프로젝트별 새 페이지는 만들지 않음 — 공통 렌더러와 데이터만 수정.
- **PDF**: Full(기존 호환, 파일명 동일) + External(최대 7쪽). External은 표지·개요·흐름 전체·서로 다른 섹션의 대표 기능 2쪽·보조 화면 1쪽·기능 카드 1쪽·마무리를 중요도 순으로 고름. 이미지 대기 프로젝트는 "외부 제출 준비 미완료".
- **PDF 용량**: 화면을 PDF 안에서만 JPEG 사본으로 넣음 — FITY 12쪽 16MB → 3.3MB. 원본 이미지는 그대로.
