# PIUS 3차 A~E 수정본 통합 검수 보고서

기준: `pius-work-v35-r3-quality-fixed.zip` / 신규 5개 작업실 수정본.

## 검증된 사실
- A 24장, B 21장, C 30장, D 3장, E 22장, 총 100개 수정 WebP.
- 100개 파일 전부 v35 원본과 파일명 일치, SHA-256 변경 확인, 디코딩 성공.
- 100개 파일 전부 각 slug의 `project.json`에 정확히 1회 등록된 파일을 교체함.
- 해상도 2880×1800 또는 1179×2556 규격 일치, 장당 1.5MB 초과 0개.
- 5개 ZIP의 압축 무결성 검사 완료, 작업실 간 충돌 파일 0개.
- 수정 파일 ZIP에는 WebP 100장만 포함하며 나머지 v35 원본 366장은 보존 대상.

## 시각 검수 결과 및 주의 사항
- 컨택트시트를 통해 100장 전체를 작업실별 비교하고 일부 대표 원본을 상세 확인함. 원본 해상도로 100장 전체를 일대일 확대 검수하거나 실제 홈페이지와 PDF에서 3개 언어·모든 반응형 조합을 확인한 것은 아님.
- A: 호텔, 아트페어, 인테리어, 스킨케어 등의 레이아웃 차별화가 전보다 뚜렷함. 기존 정상 모바일 05는 보존.
- B: 클리닉, 부동산, 가구, 후원 등의 화면 정보 구조 개선. 기존 `custom-furniture-configurator-02.webp`와 04 원본 보존.
- C: 선별 수정 요청과 달리 모바일 앱 30장 전체를 새 파일로 교체. 스타일·정보 밀도와 브랜딩이 달라졌으므로 전체 교체 전 실제 5화면 연결성을 우선 검토할 것. 특히 워커 야외 사진의 적합성과 여행 일정 지도/동선, `morrow` 명칭 중복 여부를 확인.
- D: 3장만 수정. 나머지 27장은 원본 유지. 불필요한 전면 재작업 없음.
- E: 제품별 레이아웃과 모바일 화면 차별화가 개선됨. 그러나 캠페인 소재·팟캐스트 아트워크와 건축 도면처럼 실제 텍스트·좌표·시각자료 관계는 원본 크기 추가 확인 필요. 웨딩 업체 비교는 서로 다른 사진으로 개선.

## 통합 단계 요구
- 원본 이미지 전체 재생성 금지, 수정 이미지 100장만 덮어쓰기.
- 3차 이미지 150장 중 교체 100장 + 기존 보존 50장.
- v35 전체 포트폴리오 이미지 466장 중 교체 100장 + 기존 보존 366장 (다른 이미지 자산은 별도).
- json slug/id/kind/file 참조 보존. 이미지의 내용이 크게 변한 부분은 실제 내용과 한·영·일 alt/caption을 대조해 필요한 것만 수정.
- QA·기술 검증과 실제 화면 시각 검증을 반드시 분리 보고.
- `review` 상태 임의 변경 금지; 공개 홈페이지 BI 및 공통 렌더러 보존.
- 새 ZIP을 빈 디렉터리에 추출하여 이미지 포함 여부 및 build 검증.
